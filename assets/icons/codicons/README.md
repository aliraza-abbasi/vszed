Corporation, licensed under the Creative Commons Attribution 4.0 International
license (CC BY 4.0). See `LICENSE` in this directory for the license text.

They are copied unmodified from commit
`6200d186bea39354a18737cfff73fe19dbc5fcff` (`src/icons/*.svg`). Only the icons
used by the `vscode_workbench` crate are included; add new ones from the same
source and list them in its `Codicon` enum.
